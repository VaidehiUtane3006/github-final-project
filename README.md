# Simple Interest Calculator

## Description
This project is a simple interest calculator that calculates
simple interest using the principal amount, rate of interest,
and time period.

## Formula

Simple Interest = (P × R × T) / 100

Where:
- P = Principal amount
- R = Rate of interest
- T = Time period

## Example

Principal = 1000
Rate = 5%
Time = 2 years

Simple Interest = (1000 × 5 × 2) / 100
Simple Interest = 100
